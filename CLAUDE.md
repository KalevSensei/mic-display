# Mic-stand audio display: rules for agents

Kalev's uni engineering project (see README.md). Plan: docs/PLAN.md; parts: docs/PARTS.md; CAD: cad/source/md_model.py run with C:/Users/kalev/tools/cadenv/Scripts/python.exe -I.

- Only data the PC can read is shown (owner, 2026-11-14): no sensors on the mic.
- Build order (owner, 2026-11-14): display unit, mounting interface MI-1 and desk foot first, made physical; the adapter for the classmate's microphone arm after. MI-1 dimensions never change once printed.
- Projects stay separate (owner, 2026-11-14): nothing here leans on or mentions another project; tools live in neutral folders.
- Buying advice is checked (owner, 2026-11-14): only sellers with a physical shop, or at least 300 Trustpilot reviews and a real online presence; among those, compare by delivered total to Finland (shipping, VAT, customs, real stock) in PARTS.md. The board comes from The Pi Hut ("the pi hut was actually perfect"). He orders and pays himself.
- Every order gets a delivery watch (owner, 2026-11-14; this board: docs/DELIVERY.md, task mic-board-delivery-watch): checkpoint table with the seller's dispatch days and the carrier's transit time, a scheduled check that emails Kalev per event with a ready message to the seller or carrier; duty and VAT read from the seller's live page.
- Build for the real users (owner, 2026-11-15): features only for tools Kalev, the end user and the assessors actually use and understand; cut features are parked in docs/OPEN_ITEMS.md (OBS = MD-001), never deleted.
- Spatial layout first (owner, 2026-11-15): docs/USE_SETUP.md holds who and what is where in real use (user, monitor, webcam, mic, arm, display, facing directions, distances). Check every claim about seeing, reading, reaching, glare, noise or privacy against it by tracing the actual line; measure or ask unknowns. Note: the webcam sees the back of the display, so the back of the case must look tidy.
- JHC (printing) is open Mon–Fri 8:30–18:00; printers need a staff introduction first.
- Commits stage files by name; the board STEP (18.7 MB) and assemblies stay out of git.
